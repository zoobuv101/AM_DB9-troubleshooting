ThinkDiag Numbering Caveats

2009 DB9 Coupé · 5.9L V12First-hand diagnosis · April 2026← All reference topics

From the misfire diagnosis on this car. Much of it isn't in the official workshop manual. The full story is in the misfire diagnostic report.

ThinkDiag exposes two different numbering schemes that must not be confused. The car also has two diagnostic ports: both engine ECUs (EMS-P and EMS-S) are visible together on the powertrain port, and the body and chassis modules are on the body port. A full-system scan only covers the port you're plugged into.

Live data PIDs — INJ_FAULT[0]–[5]

ECU-relative. Always 1–6, relative to whichever ECU is active in the current session. INJ_FAULT[0] = Injector 1 on the active ECU — not global Cylinder 1.

Stored DTC misfire codes — P030x

Global SAE J1979 numbering, 1–12 spanning both banks. These appear in whichever ECU session is open but reference the global scheme.

ℹ A session connected to EMS-S may return stored codes referencing global cylinder 5 — which physically lives on EMS-P. This is not a contradiction: it is a global DTC stored by the crankshaft position sensor misfire algorithm, which operates across both banks.
